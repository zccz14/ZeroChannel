# Product

## Register

product

## Users

People who need a small browser-only encryption tool and may not already know public-key cryptography terms. They want to generate a key pair, encrypt a message for a public key, and decrypt a received package with their private key.

## Product Purpose

ZeroChannel provides local-only encryption and decryption in a static web page. Success means the user can complete key generation, encryption, and decryption without accounts, servers, or hidden network dependencies.

## Brand Personality

Calm, precise, trustworthy. The interface should feel like a focused safety tool rather than a cryptography demo.

## Anti-references

Avoid cyberpunk dashboards, terminal cosplay, excessive gradients, decorative lock imagery, and dense cryptographic jargon in the main workflow.

## Design Principles

Make the safe path obvious. Explain cryptographic objects with plain labels. Keep advanced details inspectable but secondary. Prefer local browser primitives and small dependencies. Build trust through restraint and clarity.

## Accessibility & Inclusion

Aim for WCAG AA contrast, keyboard-operable controls, visible focus states, and readable status messages. Motion should be minimal and non-essential.
